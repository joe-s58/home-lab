# SOC Home Lab

A documented home lab for practicing log analysis, alert triage, and digital forensics. This repo holds my virtual network setup, configs, and findings, along with the writeups that come out of them.

## Goals
- Build a small virtual network I can generate and investigate realistic security events on
- Practice the Tier 1 SOC workflow: collect logs, triage alerts, investigate, document
- Publish what I learn as repeatable writeups

## Contents
- `/network`: topology diagram, VM inventory, addressing and segmentation notes
- `/configs`: log forwarding, SIEM, and detection rule configurations
- `/findings`: alert-to-resolution case studies and log timeline reconstructions
- `/notes`: tooling decisions, troubleshooting, and lessons learned
